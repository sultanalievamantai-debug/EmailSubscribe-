# 📧 EmailValidatorJS

> Форма подписки на рассылку с живой проверкой email — прямо в браузере.

## 🎯 О проекте

Мини-проект на чистом JavaScript: пользователь вводит email, 
и форма **сразу** показывает, корректный он или нет — 
красная рамка + сообщение об ошибке, или зелёная рамка + успех.

Проект создан как часть моего портфолио **PortfolioForge** — 
я собираю его постепенно, шаг за шагом.

## 🎮 Как работает

1. Открой файл в браузере
2. Начни вводить email в поле
3. Если в строке есть `@` и `.` — рамка **зелёная** ✅
4. Если нет — рамка **красная** и появляется сообщение ❌
5. Нажми «Подписаться» — форма проверит email ещё раз и покажет результат

## 🛠️ Технологии

- HTML5 (форма, input, кнопка)
- CSS3 (через JS — изменение `borderColor`)
- JavaScript (Vanilla, без библиотек)

## 🧠 Что внутри (логика)

- `email.oninput` — срабатывает при каждом нажатии клавиши
  - Проверка через `includes('@')` и `includes('.')`
  - Меняет цвет рамки и текст сообщения
- `form.onsubmit` — срабатывает при отправке формы
  - `event.preventDefault()` — отменяет стандартную отправку
  - Финальная проверка email
  - Очистка поля после успеха
